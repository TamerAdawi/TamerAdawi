## Projects

**[mshmaroti](https://github.com/tamer-adawi/mshmaroti)** — Hebrew-first PWA that tracks shifts across two jobs and calculates effective ₪/hour so I can tell which one pays better in practice. Works offline, installs like a native app, exports monthly PDF reports. React + TypeScript + Dexie + jsPDF.
<sub>Built in April 2026. Live demo coming soon.</sub>

**The Arbitrage Brief** *(private)* — Fully automated daily intelligence pipeline. Scrapes 7 RSS sources (Hacker News, GitHub Trending, TechCrunch, r/Startup_Ideas, and others), runs them through a three-filter framework with Gemini 2.5 Flash, delivers a curated brief to my inbox at 7:30 AM every day. Runs on Oracle Cloud Always Free Tier. Node.js + Gemini API + Nodemailer.

**Recovery-Score** [https://github.com/TamerAdawi/recovery-score] - A recovery scoring system that pulls HRV, Resting Heart Rate, and Sleep data from Apple Watch via Apple Health, compares each metric against a personalized 14-day rolling baseline, and outputs a daily training readiness score (0-100). Built as a web app with an automated Apple Shortcuts data pipeline.. Includes a visual dashboard with score history, component breakdowns, and zone-based training recommendations. Built with vanilla HTML, CSS, and JavaScript — no frameworks, no backend, no dependencies. Hosted on GitHub Pages.
